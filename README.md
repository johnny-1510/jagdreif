# Jagdreif

Lern- und Begleit-App für Jäger und Jagdscheinanwärter in Bayern. Eine einzelne HTML-Datei, als Progressive Web App installierbar und offline nutzbar.

- **Heute:** Himmel über Starnberg in Echtzeit, Jagdzeiten, Dämmerung, Mond
- **Lernen:** Karteikarten nach den 6 Sachgebieten der bayerischen Jägerprüfung, Prüfungsübungen schriftlich, mündlich, praktisch, Revier-Quiz
- **Trainer:** Ansitz-Simulator und Treffpunkt-Trainer
- **Revier:** Ansitz-Planer, Jagdtagebuch, Wochenmissionen
- **Wissen:** Jagdzeiten-Rad und Nachschlageteil (Stand: Reform des BayJG zum 1. April 2026)

Alle Daten bleiben lokal im Browser. Lernhilfe, keine Rechtsberatung.
